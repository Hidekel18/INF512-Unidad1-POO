# INF512-Unidad1-POO
Proyecto de programación orientada a objetos - Unidad 1


En este repositorio yo voy a mostrar un ejemplo de como utilizamos Git en este caso vamos a ver cómo hacer arroz blanco al estilo dominicano.

La clase es la descripción abstracta de un conjunto de objetos, en este repositorio la clase es arroz.
El objeto es cualquier cosa del mundo que nos rodea, en este repositorio objeto pueden ser: arroz amarillo, arroz blanco, entre otros, pero nuestro objeto es arroz blanco.

Un método es cómo Cocinar el arroz.

Agregar aceite y sal al cardero.
Agregar agua.
Lavar el arroz.
Agregar el arroz al agua.
El arroz estará listo.
