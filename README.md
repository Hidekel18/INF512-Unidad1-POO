# INF512-Unidad1-POO
Proyecto de programación orientada a objetos - Unidad 1


En este repositorio vamos a mostrar un ejemplo de como utilizamos Git en este caso vamos a ver cómo hacer arroz blanco al estilo dominicano y cómo servirlo.

La clase es la descripción abstracta de un conjunto de objetos, en este repositorio la clase es arroz, específicamente arroz campo (tipo).
El objeto es cualquier cosa del mundo que nos rodea, en este repositorio objeto pueden ser: arroz amarillo, arroz blanco, entre otros, pero nuestro objeto es arroz blanco que en este caso es arroz campo.

Un método es cómo Cocinar el arroz.

Agregar aceite y sal al cardero.
Agregar agua.
Lavar el arroz.
Agregar el arroz al agua.
El arroz estará listo. 
Servir en un plato. 

En este repositorio pude aprender que Github es una app donde podemos guardar nuestros códigos y podemos actualizarlo siempre que queramos. Tuve que ver tutorial de como utilizarla ya que nunca la había utilizado pero me di cuenta que no es tan difícil, además de que esta se puede utilizar en grupo. Me dí cuenta que podemos hacer sugerencias.
